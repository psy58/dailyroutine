# 하루 한 걸음

## 화면 구성

- **시작 화면**: 학생용 일과 시작과 교사용 설정 진입점을 보여 줍니다.
- **일과 구성 화면**: 학생이 오늘 할 활동과 순서를 확인하고 일과를 시작합니다.
- **일과 진행 화면**: 현재 활동의 단계와 힌트를 확인하고 이전 또는 완료로 이동합니다.
- **마침 화면**: 완료한 일과를 확인하고 다시 하거나 시작 화면으로 돌아갑니다.
- **교사용 설정 화면**: 활동 카드와 화면별 안내 문구를 관리합니다.

## 데이터 구조

브라우저 저장소에는 다음 형태의 `state`를 하나의 고정된 `localStorage` 키로 저장합니다.

```text
state = {
  version,
  cards[{ id, name, icon, hint, steps, included }],
  routineIds,
  messages,
  progress{ routineIds, currentIndex, completedIds },
  preferences{ speechEnabled }
}
```

- `cards`: 활동 카드의 식별자, 이름, 아이콘, 힌트, 단계, 일과 포함 여부
- `routineIds`: 학생 일과에 표시할 카드 ID의 순서
- `messages`: 화면에서 사용하는 교사 설정 문구
- `progress`: 진행 중인 일과 순서, 현재 위치, 완료한 카드 ID
- `preferences`: 음성 안내 사용 여부

## 주요 기능

- 학생이 오늘의 일과를 구성하고 순서대로 진행
- 완료, 힌트, 이전, 다시 하기
- 교사가 활동 카드를 추가·수정·삭제하고 순서와 포함 여부를 설정
- 교사가 활동별 단계와 화면 안내 문구를 설정
- 브라우저 음성합성을 이용한 선택형 안내 읽기
- 진행 상태 자동 저장, 전체 초기화, 기본 예시 복원
- 키보드 탐색, 동작 줄이기 설정, 모바일 화면 대응

외부 라이브러리나 외부 자원 없이 `index.html`, `styles.css`, `app.js`만으로 동작합니다.
별도의 빌드 명령이나 빌드 산출물은 필요하지 않습니다.

## 로컬 실행

간단히 확인하려면 `index.html`을 브라우저에서 직접 엽니다. 브라우저 보안 정책 때문에 일부 기능이 제한되면 저장소 루트에서 다음 명령을 실행한 뒤 `http://localhost:8000`으로 접속합니다.

```bash
python3 -m http.server 8000
```

## 배포

### GitHub Pages

저장소의 **Settings > Pages**에서 배포할 branch를 선택하고 폴더를 저장소 root로 지정합니다. 별도의 빌드 과정은 없습니다.

### Vercel

무료 정적 배포를 만들 때 Framework Preset은 **Other**, Root Directory는 저장소 루트로 지정하고 Build Command는 비워 둡니다.

## 오프라인 범위

필요한 파일을 최초로 확보한 뒤에는 정적 로컬 파일만으로 주요 기능을 사용할 수 있습니다. 서비스 워커나 PWA 캐시를 제공하는 앱은 아니므로 웹 배포 주소를 오프라인에서 항상 열 수 있음을 보장하지 않습니다.

## 저장 데이터와 개인정보

진행 상태와 설정은 현재 브라우저의 `localStorage`에만 저장됩니다. 이름, 이메일, 전화번호, 사진 같은 개인정보를 입력받지 않습니다. `localStorage`는 암호화 저장소나 화면 잠금 기능이 아니므로 기기를 함께 쓰는 사람은 저장 내용을 볼 수 있습니다.

초기화는 저장된 진행 상태와 설정을 지웁니다. 기본 예시 복원은 앱에 포함된 11개 활동을 다시 불러옵니다.

## 음성 안내

음성 안내는 브라우저가 Web Speech API의 `speechSynthesis`와 한국어 음성을 지원할 때 사용할 수 있습니다. 사용 가능한 음성과 발음은 운영체제 및 브라우저에 따라 다르며, 지원하지 않는 환경에서도 화면 안내와 나머지 기능은 동작해야 합니다.

## 테스트

Node.js나 브라우저 없이 Python 표준 라이브러리만으로 정적 계약을 확인합니다.

```bash
python3 -B -m unittest discover -s tests -v
```
